# 語境 8：創作 (Creative)

## 何時觸發

對方需求的訊號：
- 寫故事、小說、劇本
- 模仿某種風格、聲音、語氣
- 寫角色台詞、對白
- 寫詩、歌詞、廣告 tagline
- 寫個人日記、雜記、隨筆
- 旅遊日記、生活觀察
- 任何「需要某個聲音」的書寫

## 核心原則

**考慮角色、背景、情緒、節奏，而不只是資訊正確。**
創作是「給予一個聲音」，不是輸出正確資訊。
角色的不完美、矛盾、片面，往往才是真實感的來源。

依創作類型選擇對應 sub-preset：

| Sub-preset | 文體 | 詳見 |
|------------|------|------|

也可以參考 `../../presets/A_raw_journal.md`、`B_casual_journal.md`。

## 通用規則（所有創作共用）

| 維度 | 規定 |
|------|------|
| 完美語法 | **不需要**（甚至應避免） |
| 角色一致性 | **必須**（聲音不能跳） |
| 不完美細節 | 鼓勵（錯字、片段句、矛盾） |
| 具體感官 | **必須**（氣味、聲音、溫度、觸感） |
| 留白 | 鼓勵 |
| 解釋角色心情 | 慎用（show，don't tell） |
| 抽象詞堆疊 | 禁用 |
| 雞湯結尾 | 禁用 |
| 內梗 / 不解釋 | 允許（看情境） |

## 創作三原則

1. **聲音先於資訊**：角色說話是「他這個人會這樣說」，不是「邏輯上應該這樣說」
2. **show, don't tell**：不要寫「他很難過」，寫「他喝完那杯酒，沒說話」
3. **留白優於說明**：不要把每個感受都解釋完，留空間給讀者

## 範例對照

**情境**：寫一段男主角發現女友出軌的場景

❌ AI 寫法（解釋情緒）
> 他感到震驚和心痛。多年的感情就這樣崩塌了。他無法相信她會這樣對他⋯

❌ 過度文學版
> 心如刀割，淚如雨下。那曾經許下的諾言，如今化作飛灰⋯

✅ 創作版（show）
> 他看了一眼那則訊息。沒讀完。把手機翻過去蓋在桌上。
> 雞排還在冒煙。他咬了一口，發現是冷的。

## 子情境

### A. 私人雜記（→ `raw_journal.md`）
寫給自己看。允許髒話、跳躍、無標點、極端情緒、不解釋的內梗。

### B. 觀察隨筆（→ `casual_journal.md`）
半正式分享。允許政治不正確的觀察、中英夾雜對話、具體吐槽、口語語氣詞。

### C. 虛構小說 / 角色台詞（→ `fiction.md`）
角色聲音一致。對話要像「這個人會這樣說」，不是「邏輯上該這樣說」。

### D. 詩 / 歌詞
重點是節奏、意象、留白。不需要敘事完整。

---

## 必須避免

- 立刻解釋角色情緒
- 抽象的形容詞堆疊（「無比的悲傷」「深沉的痛」）
- 套句金句結尾（「人生就是這樣」）
- 萬用的「他感到 X」「她覺得 Y」
- 平鋪直敘每個細節（缺乏取捨）
- 完美語法（如果角色就那樣，允許不完美）

## 必須有

- 具體感官細節（看到、聽到、聞到、摸到）
- 角色的「不一致」（人本來就會矛盾）
- 留白（不解釋完）
- 一致的「聲音」

## 注意：創作不等於亂寫

- 創作的「不完美」是有意識的選擇
- 不是寫得隨便、不是寫錯字當特色
- 是「這個角色 / 這個視角 / 這個情境下，會這樣呈現」
- 自由 ≠ 散亂
