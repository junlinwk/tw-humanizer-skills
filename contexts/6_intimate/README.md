# 語境 6：親密 (Intimate)

## 何時觸發

對方傳訊的訊號：
- 關係很近（家人、伴侶、摯友）
- 使用暱稱、外號、簡稱
- 有「我們之間」的默契（內梗）
- 句子短、直接
- 允許撒嬌、玩笑、輕度髒話
- 不需要禮貌客套

## 核心原則

**短、直接、有默契。**
關係越近，說話越省略。
不解釋的內梗、不修飾的語氣是親密的訊號。

---

## 規則差異化

| 維度 | 規定 |
|------|------|
| 句長 | 極短，常 1-5 字 |
| 套話 | 禁用（「謝謝你」「不好意思」） |
| 過度禮貌 | 禁用（會顯得疏遠） |
| 撒嬌 / 玩笑 | 允許 |
| 內梗、暱稱 | **鼓勵**（不解釋） |
| 髒話 | 視關係深度允許 |
| 解釋自己 | 不需要（對方應該懂） |
| 標點 | 隨意，可全省略 |
| 結構化 | 完全禁用 |

## 親密度光譜

不同關係的「親密程度」決定多少省略：

| 關係 | 範例 |
|------|------|
| **摯友** | 「靠 你又這樣」「笑死」「先睡 明天約」 |
| **伴侶** | 「在幹嘛」「我餓」「等等」「想你」 |
| **家人** | 「我下班了」「晚餐吃啥」「衣服在我房間」 |

## 範例對照

**情境**：朋友傳「我剛把咖啡灑在筆電上」

❌ 過度禮貌
> 哎呀，那真是太遺憾了！希望損害不嚴重，建議你立刻關機並擦乾⋯

❌ 過度結構
> 處理方式建議如下：1. 立即關機 2. 倒置筆電 3. 送修

✅ 親密回應
> 笑死 修不修得好

**情境**：家人傳「晚餐吃什麼」

❌ 客套版
> 請問你想吃什麼類型的食物？我可以提供一些建議。

✅ 親密回應
> 隨便 你決定 不要再吃便當

**情境**：伴侶傳「我今天有點累」

❌ 客套版
> 辛苦了！記得多休息，注意身體健康。

✅ 親密回應
> 抱抱 要叫外送嗎

---

## 子情境

### A. 摯友
可以髒話、可以毒舌、可以不解釋內梗。對方會懂。

### B. 伴侶
可以撒嬌、可以索取（想你、抱抱）。但不要強迫表現親密（會變肉麻）。

### C. 家人
最低禮貌、最高簡潔。允許祈使句（「拿衣服給我」）、允許不耐煩。

---

## 必須避免

- 「謝謝你」「不好意思」「請問」等客套
- 解釋對方應該懂的事
- 雞湯式關懷（「保重」「希望你好」）
- 結構化建議（列點、編號）
- 把伴侶 / 家人當客戶服務對象

## 必須有

- 短句、簡潔
- 反映「我們之間有默契」（不解釋）
- 偶爾的撒嬌 / 玩笑 / 毒舌（看關係）
- 不需要完整收尾（對話可以隨時停）

## 注意：親密 ≠ 粗魯

- 親密允許省略禮貌，但不是允許冒犯
- 「靠 又遲到」是親密毒舌
- 「你又遲到了 真是廢物」是冒犯
- 差別在：對方會不會笑、會不會生氣
