# 語境 5：正式 (Formal)

## 何時觸發

對方需求的訊號：
- 工作信、商務 email
- 學術論文、研究報告
- 課程報告、期中期末
- 自傳、學習歷程、求職信、推薦信
- 面試自介、簡報講稿
- 公文、契約類

## 核心原則

**結構嚴謹、用語精準、少口語、不會太隨便。**
但仍須有個人指紋，否則就變成 AI 模板。

## 通用規則（所有正式文體共用）

| 維度 | 規定 |
|------|------|
| 標點 | 標準嚴謹 |
| 句子 | 完整句為主，避免片段 |
| 結構 | 允許章節、編號、條列 |
| 髒話 | 禁用 |
| 套話 | 部分允許（依 sub-preset） |
| 第一人稱 | 看子情境 |
| 制式祝願結尾 | 允許（「敬祝 X」「感謝撥冗」） |
| 個人指紋 | **必須**（套話之間要有真實內容） |

## 套話 vs AI 味的差別

**套話本身不是 AI 味**。
台灣文化中「教授您好」「敬祝教安」「感謝撥冗審查」是文化規範，這不是 AI 生成的痕跡。

**真正的 AI 味是「套話之間沒有真實內容」**。

判斷依據：
- ✅ 套話 + 真實作品名稱 / 具體數字 / 真實踩坑 / 具體個人偏好 → 人寫
- ❌ 套話 + 空泛形容詞（「優秀的學術能力」「發光發熱」）→ AI 味

## 範例對照

❌ AI 味（制式 + 空泛）
> 教授您好，我對貴系的課程非常感興趣，希望能進入就讀。我具備優秀的學術能力與學習態度，相信能在貴系發光發熱。敬祝教安。

✅ 人寫（制式 + 真實指紋）
> 教授您好，很榮幸有這次機會介紹自己。我畢業於新北市某私立高中，學測 56 級分（國 14、英 14、數 A 14、自 14）。
>
> 高中階段主要興趣是程式設計與電子實作。曾在校內程式競賽獲第三名。Arduino 專題我做過環境溫度監測器與自動植栽澆水系統，後者是因為發現第一個專題只有監測沒有 action，覺得不完整才做的⋯
>
> 敬祝 教安

**關鍵差異**：兩者都有「教授您好 / 敬祝教安」這類套話，但下面內容一個是真的、一個是空的。

## 必須避免

- 「在當今 X 的時代背景下」開場
- 空泛形容詞無支撐（「優秀」「發光發熱」「卓越」）
- 「綜上所述」+ 空話收場
- 三點工整論（每篇都剛好三點）
- 過度誇大（「徹底改變」「最關鍵」）

## 必須有

- 具體真實的個人作品 / 競賽 / 課程
- 具體選擇理由（不只是「有興趣」）
- 結構清楚
- 套話之間夾雜真實內容
