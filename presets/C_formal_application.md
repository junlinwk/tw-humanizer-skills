# Preset C: 制式申請文 / 公文 (Formal Application)

## 適用情境
自述、自傳、職涯陳述、求職信、推薦信、書信、申請動機

## 核心原則
**「制式 ≠ AI 味」。**
真正的 AI 味是「沒有個人指紋」。
這類文體在台灣教育系統有固定模板，有人本來就會用套話開頭結尾，這是文化規範不是 AI 生成。
判斷標準：去掉套話之後，剩下的內容是否有真實的個人痕跡。

---

## 規則差異化

| 維度 | C preset 規定 |
|------|---------------|
| 標點規範 | 標準嚴謹 |
| 破折號 | **允許**（中文雙破折號 ── 是正式書寫合法用法），≤ 3 次 |
| 對比結構 | ≤ 2 次 |
| 髒話 | 禁用 |
| 制式套話 | **允許**（「教授您好」「敬祝教安」「我相信」「我希望」） |
| 第一人稱 | 高密度（「我」必須） |
| 結構化 | 允許目錄、章節、編號、彩色排版 |
| 結尾 | 制式祝願允許 |

---

## 必須有的個人指紋

套話可以套，但**底下必須有真實的個人痕跡**。每篇至少要有：

1. **真實競賽 / 成績 / 作品**
   - 具體競賽名稱、名次、年份
   - 不要寫「在多項競賽中獲得獎項」這種模糊話
2. **具體課程 / 平台 / 工具**
   - 線上課程平台名、修課章節範圍、使用工具名
   - 不要寫「線上學習平台」這種空話
3. **真實踩過的坑**
   - 「初次做專題時某元件接線接錯」這類具體挫折
   - 「某科目曾經低到 X 分後重修」這類成績低谷
4. **個人偏好理由**
   - 「我選 X 是因為 Y」要有具體理由
   - 不要寫「因為我對此非常感興趣」這種廢話

## 允許的套話清單（人寫的正常用法）

開頭：
- 「教授您好，很榮幸有這次機會介紹自己」
- 「我的名字是 X，畢業於 Y」
- 「首先，我想向教授介紹我的興趣...」

承諾類：
- 「我相信這份熱忱將領導我」
- 「我會發揮 X、Y 的特質」
- 「我希望能進入貴系就讀」

結尾：
- 「最後，感謝您撥冗審查」
- 「敬祝 教安」
- 「申請人 XXX 敬上」

**前提**：這些套話之間必須夾雜真實的個人內容。

---

## 範例：制式 + 真個人指紋

```
教授您好，很榮幸能有這次機會介紹自己。我畢業於 [私立高中名]。

[個人指紋區]
- 我對 [學科] 最感興趣，並維持穩定進步
- 學測 [分數] 級分（[各科分數]）
- [全國/區域] 競賽名稱與名次
- [專題名稱]：[兩個具體實作項目]
- 線上平台修課經歷：[平台名 + 課程名]
- 自學程式語言：[語言列表]

[結尾套話可以有]
敬祝 教安
申請人 [姓名] 敬上
```

## 範例對照

❌ AI 味（制式 + 空泛，無個人指紋）
> 教授您好，我對貴系的課程非常感興趣，希望能進入就讀。我具備優秀的學術能力與學習態度，相信能在貴系發光發熱。我會努力學習，為未來打下良好基礎。敬祝教安。

✅ 人寫（制式 + 真實指紋）
> 教授您好，很榮幸有這次機會介紹自己。我畢業於新北市某私立高中，學測 56 級分（國 14、英 14、數 A 14、自 14）。高中階段我主要的興趣是程式設計與電子實作。曾在校內程式競賽獲第三名，並參加全國高中數理創意競賽進入複賽。Arduino 專題我做過兩個：環境溫度監測器（高二）與自動植栽澆水系統（高三）。後者是因為我發現第一個專題只有監測沒有 action，覺得不完整才做的。程式自學方面，國中開始用 Scratch，高中改用 Python，並修了線上一門 Python 入門課（旁聽）。最近在學 ESP32，因為想做的下一個專題會用到 WiFi。敬祝教安。

## 自審重點
判斷依據不是「有沒有套話」，而是：
- 套話之間有沒有可被驗證的真實作品 / 成績 / 課程？
- 個人偏好有沒有具體理由？
- 踩過的坑有沒有寫出來？
- 三項至少要中兩項，才算真人寫

---

## 寫作前自問
- 我有沒有具體的競賽 / 作品 / 課程可以寫？
- 我選這個科系真正的理由是什麼？（不能只是「有興趣」）
- 有沒有踩過的小坑可以放？
