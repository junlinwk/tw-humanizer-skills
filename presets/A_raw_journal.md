# Preset A: 私人雜記極限 (Raw Personal Journal)

## 適用情境
個人日記、年度回顧、放縱式書寫、極度私人的雜記、寫給自己看的內容、爛醉/情緒激動時的隨筆

## 核心原則
這是「對自己說話」的書寫，不是寫給讀者的「文章」。

---

## 規則差異化

| 維度 | A preset 規定 |
|------|---------------|
| 標點規範 | **允許完全無逗號句號**，用空格斷句 |
| 破折號 | 禁用（雜記不會用 em dash） |
| 對比結構「不是 X 而是 Y」 | 允許（口語自然會用） |
| 髒話 / 粗口 | **允許**（「他媽的爛」「幹你娘」「狗屁」諸如此類） |
| 私人語境 | **不解釋的人名、店名、活動名允許直接出現** |
| 跳躍 / 岔題 | **鼓勵** |
| 偏見 / 政治不正確 | **允許直陳，不要 hedge** |
| 黑色幽默 / 極端比喻 | **允許**（自殘、自嘲、荒謬都 OK） |
| 第一人稱 | 核心，密度極高 |
| 制式套話 | **禁用**（「我相信」「我希望」「我會」等申請文式） |
| 結構化 | 禁編號、條列、粗體 lead-in。段落分隔可用 `-` 或空行 |
| 結尾 | 開放、無厘頭、極端、平淡都 OK。**禁止雞湯總結** |

---

## 必須有的真實雜質

寫作時要主動加入以下「真實人類雜質」（AI 預設會迴避）：

1. **不解釋的內梗 / 人名**：朋友名、店名、品牌、活動直接出現
2. **黑色幽默或極端情緒比喻**：「拿玻璃碎片劃開頸動脈」這種誇張比喻 OK
3. **真實偏見直陳**：「中國大媽到底是三小」這類觀察直接寫，不政治正確化
4. **自相矛盾**：可以寫「我以為 X，後來發現也不是」
5. **情緒劇烈起伏**：從憤怒到自嘲到平淡，不需要過渡

---

## 標點風格選項

可選其一：
- **完全無標點**：「2025是個不太容易的一年 載浮載沉 也是過完了」
- **半標點**：偶爾用句號，主要靠空格斷句
- **全標點但口語**：標準標點但句子短促零碎

---

## 範例對照

❌ AI 寫法（太乾淨、太政治正確、有總結）
> 今年是充滿挑戰的一年。經歷了許多起伏，但我從中學到了寶貴的經驗。雖然過程不容易，但我感謝身邊支持我的人，讓我能夠走過這段時光。期待明年能有更好的自己。

✅ 人寫範例
> 上半年真的爛透了 期中後直接崩 三科被當 室友搬走 我那時候每天就是窩在房間打LOL 後來實在受不了開始去河堤跑步 沒有什麼勵志故事 就是想消耗體力換取睡眠 三個月後體重掉七公斤 學分也補回來了 但心情沒有比較好 只是麻木了

## 寫作前自問
- 我有真的想寫，還是在寫給別人看？（如果是後者，改用 preset B）
- 有沒有不解釋的人名、地名、內梗可以加？
- 結尾要不要極端一點、暗黑一點？（不要硬上雞湯）
